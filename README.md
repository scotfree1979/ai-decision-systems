# AI Decision Systems — Real-Time & Simulated Environments

This repository showcases my work in building structured decision systems across both real-world and simulated environments.

---

## Overview

My focus is on designing systems that:

- Process inputs continuously  
- Evaluate conditions in real time  
- Execute structured, multi-step decisions  

These systems are designed to operate under real-world constraints such as latency, uncertainty, and execution risk.

---

## 1. AutoScalp — Real-Time Decision Engine (Private)

A large-scale Python system (~50k+ lines) built to process live data, evaluate opportunities, and execute actions in real time.

### Key Characteristics:
- Real-time data processing pipeline  
- Structured decision engine  
- Multi-step execution logic  
- Risk and validation layers  
- Observability and debugging systems  

This system operates in a live environment and is not publicly available.

---

## 2. Poker Decision Engine — Simulated Environment (Partial)

A decision engine built using a poker environment to model structured reasoning under uncertainty.

### Purpose:
- Test decision-making logic in a controlled setting  
- Explore multi-step reasoning  
- Validate system behaviour before real-world deployment  

### Concepts:
- Input evaluation  
- Action selection  
- Sequential decision flow  

---

## Design Approach

Across both systems, the focus is on:

- Structured system design  
- Clear decision-making logic  
- Controlled execution  
- Real-world applicability

# 4️⃣ REAL-WORLD HOOK SYSTEM (v2) + TEMPORAL HOOK LAYER
# ===============================================================

Structure:  
1️⃣ Real-World Trigger — specific, named event  
2️⃣ Emotional Spike  — universal reaction  
3️⃣ Concept Bridge   — pivot into UBS theme

Example:  
“Storm Melissa ripped through half the coast this week — houses gone, lives scattered.  
Everyone saw destruction.  
But sometimes loss is just tuition in disguise.”

Rotation plan:  
• Market Days → economic shocks  
• Off Days → tech / social trends  
• Transition Days → sports events  
• Milestone Days → seasonal or world events


# ===============================================================
# 5️⃣ ANALOGY + C.A.M. LAYER — COMPREHENSION, ANALOGY, MEMORY
# ===============================================================

Purpose: translate complex ideas into emotional understanding.

Rules:  
• ≤ 1 analogy every 60–90 seconds  
• Mix analogy → fact → pause → metaphor  
• Archetypes per UBS pillar (e.g., L.O.S.E. = forge; R.I.S.K. = tightrope; etc.)

C.A.M. block syntax:

[CONCEPT] short statement  
[C.A.M.] concise analogy  
[FREE FLOW] improv expansion
